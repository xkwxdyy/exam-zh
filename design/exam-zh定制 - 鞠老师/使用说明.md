# 使用说明

## 快速开始

在项目根目录执行 `make doctor` 检查 MacTeX/BasicTeX 和必要文件。开发时使用：

```zsh
make single                 # 编译单份试卷
make multiple               # 编译多卷试卷
make compile FILE=foo.tex  # 编译根目录中的其他入口
```

所有辅助文件和日志写入 `build/aux/`，最新 PDF 写入 `build/pdf/`。源目录不会再累积 `.aux`、`.log`、`.solution` 等文件。

提交或交付前执行 `make test`。该命令会检查环境并完整编译 `example-single.tex` 与 `example-multiple.tex`。

## 打包

```zsh
make package VERSION=2.12 DATE=2026-08-21
# 双击或直接执行兼容入口：
zsh 打包.command 2.12 2026-08-21
# 只检查，不落盘：
zsh scripts/workflow.zsh package --dry-run 2.12 2026-08-21
# 覆盖 dist 中的同名包（必须显式确认）：
make package VERSION=2.12 DATE=2026-08-21 FORCE=1
# 已经单独完成测试时，可跳过打包前的编译检查：
zsh scripts/workflow.zsh package --skip-test 2.12 2026-08-21
```

版本号和日期省略时，版本号自动递增 `exam-zh-pro.cls` 的最后一段，日期取当天。打包默认先编译两个示例；脚本还会拒绝无效日历日期、同名包覆盖和并发打包。压缩包先在临时目录组装并通过完整性检查，再原子写入 `dist/`；检查失败不会修改 class 文件。

## 清理

`make clean` 或双击 `清理临时文件.command` 会清空并重建 `build/`。`build/` 和 `dist/` 都是可再生目录，不应手工加入源文件。

多卷入口使用 `\IncludeExamPaper{目录标题}{Parts/分卷文件}`，第二个参数不写 `.tex` 后缀。每个分卷放在 `Parts/` 中。
